# ROMP Twin Simulation Code

This repository contains the replication code and simulation environment for the model presented in our manuscript. 

## Structure
- `ROMP_twin.py`: Core simulation framework (`ROMPTwin`, Channels).
- `ROMP_helpers.py`: Volume initialization and data processing helper functions.
- `demo.ipynb`: A minimum viable demonstration notebook showcasing a standard simulation run.

## Setup Instructions

1. **Clone or download** this repository to your local machine.
2. **Install dependencies** using pip:
   ```bash
   pip install -r requirements.txt
   ```
3. **Run the demo:** Open `demo.ipynb` using Visual Studio Code or Jupyter Lab and run all cells to generate a simulation state report.
